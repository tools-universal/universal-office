# Padrões de hifenização — avisos de terceiros

Os módulos desta pasta são gerados por `write/tools/hyphen/gen-patterns.mjs` a partir dos
arquivos de padrões do projeto hyph-utf8 (https://github.com/hyphenation/tex-hyphen),
para o algoritmo de Frank Liang implementado em `../liang.ts`. Cada módulo mantém o
aviso de copyright e a licença do seu arquivo de origem, reproduzidos abaixo.
