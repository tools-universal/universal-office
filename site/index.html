Why Universal Office?

Three architecture decisions other editors don't make.

Lossless round-trip

The data model mirrors OOXML — no "pretty" abstraction that breaks compatibility. Parts and attributes not yet modeled are preserved byte for byte on save.

Faithful rendering

A custom line breaker using real font metrics (TTF/OTF parsing). Every line break and glyph position replicates the reference app — the same pagination, every time.

Observed behavior, not guessed

Every editing operation is specified by automated experiments against the reference application: the resulting XML diff becomes a regression test, and the exported PDF becomes a pixel-by-pixel layout comparison.
