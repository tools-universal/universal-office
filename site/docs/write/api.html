API reference

Public methods and properties of the UniversalWriteElement class (the <universal-write> element), grouped by area.

Built-in chrome (toolbar & status bar)

The component can render its own top toolbar and bottom status bar — no external chrome to wire. They are set via attributes (or the matching properties) and load Material on demand, so the default costs nothing.

Attribute / propertyTypeDescription
topbarboolean attributeTop bar with menus, find & replace, comments beside the page, open/save (File System Access or the host), autosave, recent files, Protected View, compare, theme, focus/read modes, context menu and drag & drop.
toolbarcompact · ribbonStyle of the top bar: compact (default — File/Edit/View/Insert/Format/Tools/Help menus plus one toolbar row that collapses by priority, like Google Docs) or ribbon (tabs, groups with dialog launchers and contextual tabs, like Word).
bottombarboolean attributeBottom status bar: page/word count, view switch, zoom.
 
<universal-write topbar bottombar></universal-write>
<universal-write topbar toolbar="ribbon" bottombar></universal-write>
// or at runtime, via properties
editor.topbar = true;     // boolean
editor.bottombar = true;  // boolean
editor.setAttribute('toolbar', 'ribbon');

// optional: what only the host app can do (e.g. an Electron shell)
editor.host = {
  openFile: () => bridge.open(),                 // { name, bytes, motw? } | null
  saveFile: (bytes, { name, format, saveAs }) => bridge.save(bytes, name),
  setDirty: (dirty, name) => bridge.setDirty(dirty, name),
  windowControlsOverlay: true,                   // frameless window
};

Commands whose editor API does not exist yet stay hidden, so new editor features appear in the bars as soon as their method exists.

The bars are themed with Material Design 3 (theme and accent color are scoped to the element; tune them with --uw-font, --uw-desk, the --uo-* variables or ::part()) and follow light/dark mode, and their controls reflect the current selection (active buttons, current style, font, size, and color).

Document (load, save, export)

MethodDescription
load(bytes, format?, opts?)Loads a document. format: 'auto' (default — detects .docx vs .odt from the bytes; Word 97–2003 .doc is detected and converted), 'docx', or 'odt'. opts.protected (default true) opens in Protected View.
save(format?, opts?): Promise<Uint8Array | string>Saves/exports the document. format: 'auto' (default — the format it was loaded as), 'docx', 'odt', 'pdf', 'html', 'markdown', 'xps'. Returns bytes for binary formats and a string for html/markdown. opts: { images?: boolean, title? }.
newDocument()Creates an empty, editable document.
initialize(options)Initializes with fonts/document as bytes (offline mode). Called automatically on connect unless manual-init is set; calling it again does nothing. Returns Promise<void>.
getFontEmbedding() · setFontEmbedding(settings)Fonts in the saved .docx: { embed, subset, skipCommonFonts }. Default: off. uw-font-embedding reports what was embedded.
requestSystemFonts(): Promise<boolean>Asks for Local Font Access (Chromium) so installed fonts can be measured and embedded. Call from a user gesture.
listAvailableFonts(): Promise<string[]> · knownFontFamilies()Font families the editor can use / has loaded (for a font picker).
exportPdf() · exportXps() · exportHtml(title?, opts?) · exportMarkdown(title?, opts?) · exportOdt(opts?)Lower-level exporters behind save().
print()Opens the print dialog with pages in Print mode.

Document state

MethodDescription
isProtected(): booleantrue if in Protected View.
enableEditing()Leaves Protected View and unlocks editing.
hasExternalFields(): booleantrue if the document has fields (TOC, PAGE, DATE, etc.).
currentPage(): numberPage visible at the center of the viewport (1-based).
stats()Returns { pages, words, chars, paragraph, page }.
selectedText(): stringPlain text of the selection (paragraphs separated by \n).
getSelectionState()Caret props and UI state: { run, para, view, marks }.
selectAll() / focusEditor()Selects everything / gives keyboard focus to the editor.
undo() / redo()Undoes / redoes the last action.

View and zoom

MethodDescription
setView(v) / getView()View mode: 'print' | 'web' | 'draft' | 'read' | 'outline'.
setZoom(z, anchorY?) / getZoom()Zoom from 0.1 to 5 (10%–500%).
toggleMarks(): booleanShows/hides paragraph marks; returns the new state.
setDarkPage(dark)Dark theme: inverts the luminance of page colors.

Text formatting (runs)

MethodDescription
toggleRunProp(key)Toggles 'bold' | 'italic' | 'underline' | 'strike' | 'allCaps' | 'smallCaps'.
toggleVertAlign(kind)Toggles 'superscript' | 'subscript'.
setFontSize(pt) / growFont(delta)Sets size in points / grows-shrinks in steps.
setFontFamily(name)Sets the family (e.g. 'Calibri', 'Aptos').
setColor(hex?)Text color (e.g. '1A73E8'); undefined resets to default.
setHighlight(name?)Highlight: 'yellow' | 'green' | 'cyan' | 'magenta' or undefined.
setCharSpacing(twips?)Character spacing, in twips.
setLink(url?)Applies/removes a hyperlink on the selection.
changeCase(mode)Converts the selection: 'upper' | 'lower'.
clearFormatting()Removes all direct formatting from the selection.
copyFormat() / painterActive()Format painter: activates / checks whether it is active.

Paragraph formatting

MethodDescription
setAlignment(a)'left' | 'center' | 'right' | 'both' (justified).
applyStyle(styleId?)Applies a paragraph style (e.g. 'Heading1').
toggleList(kind)Toggles a 'bullet' | 'decimal' list.
indent(delta)Grows/shrinks the left indent (1 | -1; step of 720 twips = 0.5").
setSpecialIndent(kind)'none' | 'firstLine' | 'hanging'.
setIndentRight(twips?)Right indent.
setLineSpacing(line)Line spacing in twentieths of a point (240 = 1.0; 360 = 1.5).
setSpaceBefore(twips?) / setSpaceAfter(twips?)Space before/after the paragraph.
setShading(hex?)Paragraph background color.
toggleBorder()Toggles paragraph borders.

Units: the API uses the format's native units — twips (1/20 of a point) for layout measures and points for font size. Conversions to pixels happen only at render time.

Inserting content

MethodDescription
insertPageBreak()Inserts a page break.
insertField(kind)Inserts a 'PAGE' | 'NUMPAGES' | 'DATE' field.
insertImage(data, ext): Promise<void>Inserts an image ('png' | 'jpeg' | 'gif').
insertCustomInline(type, data, opts?)Inserts an atomic plugin inline (see Plugins).

Clipboard, find and replace

MethodDescription
copy() / cut() / paste()Async; keep a rich clipboard internally.
pastePlain()Pastes as plain text, without formatting.
findNext(needle): booleanSelects the next occurrence (case-insensitive); true if found.
replaceAll(needle, replacement): numberReplaces all occurrences; returns the count.

Header and footer

MethodDescription
enterHeaderFooter(kind, activePage?)Enters editing of a page's 'header' | 'footer'.
exitHeaderFooter()Leaves editing and returns to the document body.
editingHeaderFooter()Returns 'header' | 'footer' | null.

Comments

MethodDescription
addComment(text, author?): number | nullComments the current selection; returns the ID (or null if the selection is empty).
removeComment(id)Removes the comment.
getComments()Lists { id, author?, text }[].
goToComment(id)Navigates to and selects the commented range.
commentAnchorPx(id)Anchor position in pixels — { topPx, heightPx, page } | null — for drawing UI alongside.

TOC, navigation and page setup

MethodDescription

setPageSetup(opts){ orientation?: 'portrait' | 'landscape', size?: 'A4' | 'Letter', margins?: 'normal' | 'narrow' | 'wide', customMargins?: { top, right, bottom, left } } (custom margins in twips).
