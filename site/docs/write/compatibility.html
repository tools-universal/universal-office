Compatibility

An audited matrix of .docx format features and reference-application behavior. Each row is validated by automated experiments (XML round-trip and visual comparison via PDF/pixel diff).

How the matrix is audited

No item is marked "complete" based on reading a specification. Each feature is validated against the reference application with automation:

  • Format: an operation is applied in the reference app, the before/after .docx is extracted, and the XML diff becomes the observed specification — and then a regression test.
  • Rendering: the reference app exports to PDF/XPS; the result is rasterized and compared pixel by pixel with Write's layout engine.
