Events

<universal-write> communicates with the host app through CustomEvents. All use the uw- prefix; the payload is in event.detail. 

editor.addEventListener('uw-ready', (e) => {
  console.log('offline?', e.detail.offline, 'plugins:', e.detail.plugins);
});

Lifecycle and document

EventdetailFires when
uw-ready{ offline: boolean, plugins: string[] }Component initialized: fonts loaded and document ready.
uw-change—The document is about to change — it fires before the edit is applied, so read the new state on the next frame (e.g. requestAnimationFrame). Use for dirty tracking and autosave.
uw-protected{ active: boolean, hasFields: boolean }Protected View turned on/off.
uw-blocked{ reason: 'protected' }Header/footer editing was refused because the document is in Protected View.
uw-font-embedding{ embedded: string[], skipped: { family, reason }[] }After saving a .docx with font embedding on; reason is 'common', 'license' or 'unavailable'.

Interface

EventdetailFires when
uw-zoom{ zoom: number }The zoom changed (shortcut, gesture, or setZoom).
uw-styles-change—The style sheet changed (create, modify, rename, delete or undo/redo of a style).
uw-hfmode{ active: boolean, kind?: 'header' | 'footer' }Entered/left header or footer editing.
uw-hfhover{ kind?: 'header' | 'footer', x?: number, y?: number }Mouse over the header/footer region (to show a hint).
uw-tbmode{ active: boolean }Entered/left text-box editing.
uw-cellmode{ active: boolean }Entered/left table-cell editing.

Text input

EventdetailFires when
uw-before-input{ text: string } (cancelable)Before text is inserted. preventDefault() cancels the insertion — this is how plugins intercept triggers like @.
uw-input{ text: string }After text is inserted.

Comments

EventdetailFires when
uw-comments-changed—A comment was added or removed.
uw-comment-click{ ids: number[] }Click on a commented range in the document.

Plugins

EventdetailFires when
uw-plugin-added{ id: string }Plugin installed via use().
uw-plugin-removed{ id: string }Plugin removed via unuse().
uw-custom-inline-inserted{ type: string, data: any, fallbackText: string }Custom inline inserted into the document.

Recipe: reactive status bar

const status = document.getElementById('status');

editor.addEventListener('uw-change', update);
editor.addEventListener('uw-zoom', update);

function update() {
  const st = editor.stats();
  const zoom = Math.round(editor.getZoom() * 100);
  status.textContent =
    `Page ${st.page} of ${st.pages} · ${st.words} words · ${zoom}%`;
}

Recipe: "Enable Editing" bar

editor.addEventListener('uw-protected', (e) => {
  banner.hidden = !e.detail.active;
});

bannerButton.onclick = () => editor.enableEditing();
