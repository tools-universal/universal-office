<universal-sheet>

The <universal-sheet> web component — an .xlsx editor that draws the grid to a canvas with the look of Microsoft Excel: column widths and row heights from the workbook, number formats, fonts, borders, merged cells, conditional formatting, charts, images and shapes. Formulas are recalculated by a built-in engine with Excel's functions.

Package @universal-office-pro/sheet

  • Opens .xlsx and .xls (Excel 97–2003, converted in memory); saves .xlsx, rewriting only what was edited
  • Inline cell editing typed like Excel (numbers, dates, percentages, currency, booleans, formulas) with function autocomplete
  • Recalculation of dependent cells across all sheets on every edit
  • Formula language and number separators follow the user's locale (=SUM(A1,1.5) or =SOMA(A1;1,5))
  • Frozen panes, hidden rows/columns, hyperlinks, comments, right-to-left sheets
  • Zoom, resizable rows and columns (double-click to autofit)

Installation

Obtain the package from PrivJS and follow the setup instructions there.

The package is self-contained — no dependencies. Serve these folders next to index.js:

PathWhat it is
index.jsThe component (registers <universal-sheet> on import)
chunks/Parts loaded on demand
fonts/Open fonts used as metric-compatible substitutes (see Fonts)
 
import { FontResolver } from '@universal-office-pro/sheet';

FontResolver.shared().configure({ baseUrl: '/office/fonts' }); // the package's fonts/

const sheet = document.querySelector('universal-sheet');
sheet.loadXlsx(new Uint8Array(await (await fetch('/budget.xlsx')).arrayBuffer()));
sheet.addEventListener('us-selection', (e) => console.log(e.detail.ref, e.detail.edit));
<universal-sheet style="display:block; height:100vh"></universal-sheet>

Give the element a size with CSS — it fills its box.

Attributes and properties

Attribute / propertyDescription
formula-locale / formulaLocaleLocale of formulas and numbers (BCP 47). pt* uses Portuguese function names, errors and booleans (=SOMA, #N/D, VERDADEIRO); anything else uses English (=SUM, #N/A, TRUE). The decimal separator comes from the region; the argument separator is ; when the decimal is ,. Default: the browser's language.
langUI language (en · pt). Without it: Portuguese if the browser prefers it, otherwise English.
fileNameFile name reported by CELL("filename"). Set before loading.
shouldRecalcOnOpen(workbook) => boolean. Return true to recalculate everything on open; otherwise the values saved in the file are shown, like Excel.
onSelectionChangeCallback form of us-selection.
activeCellEditTextWhat a formula bar should show for the active cell.

A minimal formula bar:

const bar = document.querySelector('#formula');
sheet.attachFormulaBar(bar);
sheet.addEventListener('us-selection', () => { bar.value = sheet.activeCellEditText; });
bar.addEventListener('keydown', (e) => {
  if (e.key === 'Enter') sheet.setActiveCellText(bar.value);
});

Fonts

The default font of a workbook (Aptos Narrow, Calibri…) defines the column widths, so it matters. Families resolve, in order: fonts the browser can see by name (installed or declared with @font-face) → metric-compatible open substitutes from the folder given to FontResolver (Calibri → Carlito, Cambria → Caladea, Arial → Liberation Sans, Times New Roman → Liberation Serif, Courier New → Liberation Mono) → Liberation Sans. Serve the package's fonts/ and point FontResolver.shared().configure({ baseUrl }) at it.

Keyboard and mouse

Arrows move (leaving merged cells by their edge), Home · End go to the first and last column, PageUp · PageDown move 10 rows, typing starts editing, F2 or Enter edit the current content, Delete · Backspace clear. While editing: Enter commits and moves down, Tab · Shift+Tab commit and move sideways, Escape cancels. Wheel scrolls (Shift for horizontal); drag a header border to resize, double-click it to autofit; double-click a cell to edit; hover a red-cornered cell to read its comment.

Current limitations

One cell is selected at a time (no range selection), and there is no copy and paste yet.
