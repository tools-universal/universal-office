<universal-document-viewer>

The <universal-document-viewer> web component: a read-only viewer for .docx and .doc files with layout faithful to Microsoft Word — the same pagination, line breaks and page images as the editor and the PDF export, because all three use the same layout engine.

Package @universal-office/document-viewer

  • Print, Read and Web views, zoom (page width, whole page or a percentage)
  • Side panel with page thumbnails and the document outline (headings)
  • Comments panel linked to the highlighted text
  • Selectable, searchable text (invisible text layer over the canvas)
  • Download the original file or a PDF, print and full screen; PDF export
  • Keyboard and screen-reader accessible; English and Portuguese UI

Installation

The package is self-contained: one ES module plus two folders that must be served next to it.

PathWhat it is
index.jsThe component (registers <universal-document-viewer> on import)
chunks/Parts loaded on demand (hyphenation patterns, rare converters)
fonts/Open fonts (Liberation, Carlito, Caladea) used as metric-compatible substitutes
 
import '@universal-office/document-viewer';
<universal-document-viewer src="/report.docx" fonts="/node_modules/@universal-office/document-viewer/fonts"
  style="display:block; height:100vh"></universal-document-viewer>

Give the element a size with CSS — it fills its box.

Attributes

AttributeValuesDescription
srcURLDocument to fetch and show (same origin or CORS). Reloads when changed.
fontsURLFolder with the open fonts. Default: the package's own fonts/, next to index.js — set it only when you serve the fonts from somewhere else (or when the bundle is loaded from a blob:/data: URL). Read once, on the first layout.
viewprint (default) · read · webInitial view.
zoompage-width (default) · page-fit · number or %Initial zoom, e.g. 125 or 125% (10–800%).
noselectbooleanTurns off text selection.
nocontrolsbooleanRemoves the whole control bar.
no<item>booleanRemoves one control: nonav, nocounter, nooutline, nothumbnails, nocomments, nozoom, noview, nodownload, nodownloadpdf (the Print button then prints directly, with no Save as PDF option), noprint, nofullscreen, noprogress.
langen · ptUI language. Without it: Portuguese if the browser prefers it, otherwise English.

Methods

MethodDescription
loadDocx(bytes: Uint8Array): Promise<void>Loads a .docx or .doc. Throws on an invalid file and keeps the current one.
getPageCount() · getPageIndex()Page count and current page (0-based).
goToPage(i, smooth = true)Scrolls to a page.
getView() · setView('print' | 'read' | 'web')Current view.
getZoom() · setZoom(spec)spec is 'page-width', 'page-fit' or a factor (1 = 100%, 0.1–8). getZoom() returns { spec, factor }.
getHeadings() · goToHeading(i)Outline: { level, text, page }[].
getComments() · selectComment(id)Comments: { id, author, text, page }[].
exportPdf(): Uint8ArrayPDF of the print layout.
print() · download() · downloadPdf() · toggleFullscreen()Same as the control-bar buttons: Download saves the original file; Print opens a menu with Print… and Save as PDF (downloadPdf(), the PDF of the print layout).
 
const viewer = document.querySelector('universal-document-viewer');
const bytes = new Uint8Array(await (await fetch('/contract.docx')).arrayBuffer());
await viewer.loadDocx(bytes);
viewer.setZoom('page-fit');

Fonts

Fonts embedded in the document are used first. Other families are resolved, in order, from: fonts the browser can see by name (installed or declared with @font-face), then metric-compatible open substitutes from the fonts folder (Calibri → Carlito, Cambria → Caladea, Arial → Liberation Sans, Times New Roman → Liberation Serif, Courier New → Liberation Mono), then Liberation Sans. Serving fonts/ keeps line breaks right when the reader does not have the Office fonts. The package also exports FontResolver for advanced setups:

import { FontResolver } from '@universal-office/document-viewer';
FontResolver.shared().configure({ baseUrl: '/assets/office-fonts' });

Formats
