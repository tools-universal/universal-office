# Development

Maintenance guide for the Universal Office repository
(<https://github.com/erichideyuki/universal-office>). The public showcase is the root
`README.md` and the site <https://universaloffice.org/> (the content of
`site/`, in English). The repository folder is still called `OfficeNext`, the project's
old name — do not use it in new code, packages or docs.

Office suite with format compatibility and rendering faithful to
Office: word processor (Write, .docx), spreadsheet (Sheet, .xlsx) and presentation
(Slides, .pptx). Each editor exists as a **web component**, as a **desktop
app** and, for servers, as a **.NET library**. MIT license (`LICENSE`).

Repository rules (proprietary fonts, "one place only" for each engine,
packages, publishing): `CLAUDE.md`. History: `CHANGELOG.md`. npm and
NuGet publishing: `docs/publishing.md`.

## Structure

| Folder | Contents |
|---|---|
| `write/` | Write: `docx-core`, `docx-layout` (layout engine), `editor`, `viewer`, `compare`, Word labs (`tools/`) — `write/ARCHITECTURE.md` |
| `sheet/` | Sheet: `sheet-core`, `calc`, `sheet` — `sheet/ARCHITECTURE.md` |
| `slides/` | Slides: `slides-core`, `slides`, `viewer` (`@universal-office/slides-viewer`) — `slides/ARCHITECTURE.md` |
| `shared/` | Common engines: `fonts`, `charts`, `drawingml`, `ui`, `spell` (and the data packages `font-files`, `spellcheck`, `dictionary-*`) |
| `desktop/` | The suite's desktop app (Electron): the three editors in a single app — `desktop/RELEASING.md` |
| `dotnet/` | .NET port (`UniversalOffice.sln`) — `dotnet/README.md` |
| `site/` | Static site (landing + documentation), published at <https://universaloffice.org/> |
| `tools/` | Publishing build (`build-pkg.mjs`), JS × .NET parity, fonts, site, GIFs |
| `vendor/office-converter` | Git submodule of the format converter (`git submodule update --init`) |
| `docs/` | This guide and the publishing step-by-step |

## Commands

```bash
npm run install:all   # hooks, local fonts, converter, dependencies and builds of the common packages, desktop app
npm run build
npm test
npm run build:pkg     # publishable folders in <package>/publish/
npm run docs:site     # site pages generated from the package READMEs
npm run docs:gifs     # re-records the GIFs in site/assets/gifs
npm run desktop       # desktop app in dev (-- --editor=sheet, a file, or nothing: welcome screen)
```

Proprietary fonts (Aptos, Calibri…) never go into the repository:
`npm run fonts:sync` (part of `install:all`) copies the ones installed on the machine
to the local folders, which are in `.gitignore` (see `CLAUDE.md`).

## Web components (npm)

All packages ship with the SAME version (currently 0.9.2), including the NuGet ones.

| Package | Component | Version |
|---|---|---|
| `@universal-office/write` | `<universal-write>` (.docx editor; `./viewer` entry with the viewer only) | 0.9.2 |
| `@universal-office/document-viewer` | `<universal-document-viewer>` (read-only, .docx/.doc) | 0.9.2 |
| `@universal-office/compare` | `<universal-write-diff>` + .docx diff engine | 0.9.2 |
| `@universal-office/slides-viewer` | `<universal-slides-viewer>` (.pptx/.ppt; replaces `@universal-office/presentation-viewer`, deprecated) | 0.9.2 |
| `@universal-office/sheet` | `<universal-sheet>` (.xlsx editor) | 0.9.2 |
| `@universal-office/slides` | `<universal-slides>` (.pptx editor) | 0.9.2 |
| `@universal-office/font-files` | metric-compatible open fonts (OFL-1.1 and Apache-2.0) | 0.9.2 |
| `@universal-office/spellcheck`, `@universal-office/dictionary-pt-br`, `@universal-office/dictionary-en-us` | optional spell checking for write (Hunspell in WASM and dictionaries) | 0.9.2 |
| `@universal-office/dictionary-es` | Spanish dictionary (RLA-ES, all variants) for spell checking | 0.9.2 |

The published manifest (generated by `tools/build-pkg.mjs`) carries `homepage`
(<https://universaloffice.org/>), `repository` (this repository, with the package
folder), `bugs` and `funding` (GitHub Sponsors).

Each product's documentation is the package README (in English, it goes to npm) and
the site (`site/`): `npm run docs:site` (`tools/site/gen-docs.mjs`) generates the
pages for `document-viewer`, `sheet`, `slides` and `slides-viewer` from
the READMEs and rewrites the sidebar of all of them; the Write pages
(`site/docs/write/`) and the diff pages (`site/docs/universal-write-diff/`) are written
by hand. A generated page is not edited: change the README and run the generator.

## .NET library (NuGet)

`UniversalOffice.Core` and `UniversalOffice.Docx` (0.9.2): read, edit, sanitize and
apply templates to .docx and generate PDF with the same layout engine as the editor.
`UniversalOffice.Xlsx` and `UniversalOffice.Pptx` are packed, but not
published yet. Common metadata (version, `PackageProjectUrl`, `RepositoryUrl`) in
`dotnet/Directory.Build.props`. See `dotnet/README.md`.

## Desktop app (Beta)

The three editors ship together in a single desktop app, **Universal Office (Beta)**
0.9.2 (`desktop/`), for Windows (installer), macOS (dmg, Apple Silicon and
Intel) and Linux (AppImage, deb, rpm, tar.gz and Snap; Flathub planned). One
installation, one runtime, three editors, each with its own shortcut, icon and
window:

| Editor | Opens |
| --- | --- |
| **Universal Write (Beta)** | .docx, .doc, .odt; built-in pt-BR, en-US and es spell checker |
| **Universal Sheet (Beta)** | .xlsx, .xlsm, .xls; exports PDF, ODS, CSV, TSV, HTML, Markdown and XML 2003 |
| **Universal Slides (Beta)** | .pptx, .ppt; slideshow with animations |

Download: [Windows](https://github.com/erichideyuki/universal-office/releases/download/desktop-v0.9.2/Universal-Office-0.9.2-beta-Setup.exe)
· [all formats](https://github.com/erichideyuki/universal-office/releases/tag/desktop-v0.9.2)

The Windows installer creates the "Universal Write (Beta)", "Universal
Sheet (Beta)" and "Universal Slides (Beta)" shortcuts; each one opens the editor's
welcome screen (new, open, recent files, language), and a file opened by the system goes
to the editor for its extension. Interface in Portuguese, English or Spanish
(on the welcome screen or in each editor's Language menu, stored in the profile;
default: the system language). Command line: `--editor=write|sheet|slides`
opens the editor's welcome screen (`--app=` is an alias), `--new-window` opens a
new document and the files passed open in the editor for their extension. On Linux, the
deb, the rpm and the Flatpak install the three launchers; the AppImage has only one (the
welcome screen of the last editor used). The app works offline: the open fonts
ship with it, the system fonts (such as Calibri) are read from the machine and never
distributed, and the theme follows the system's light/dark setting. The builds are not
signed yet, so SmartScreen and Gatekeeper show warnings on installation.

- **Linux stores:** Snap Store (`universal-office`, beta channel), Flathub
  (`org.universaloffice.UniversalOffice`, with the three launchers) and
  AppImageHub. Publishing to the stores is still manual.
- **Releases:** they come from the `desktop-v<version>` tag through the "Release
  desktop" workflow (`.github/workflows/release-desktop.yml`) to this
  repository's Releases, as a pre-release (draft). Step-by-step,
  tests (`smoke`, `smoke:packaged`) and store configuration in
  `desktop/RELEASING.md`.
- On the site, the download links live in one place only: `site/assets/downloads.js`.
